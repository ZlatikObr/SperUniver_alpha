# Пульс — AI-инструмент первичного бизнес-скрининга

**Интенсив:** AI-driven PDLC · 4–6 мая 2026 · Бизнес-школа МФТИ × СберУниверситет

Консалтинговое агентство встраивает Пульс в процесс продаж: клиент проходит адаптивный опрос, прикрепляет отчётность, получает диагностику по 5 зонам и готовое КП — за 20 минут вместо 3–7 дней.

---

## Быстрый старт (2 команды)

Требуется **Python 3.10+**.

```bash
pip install -r requirements.txt
streamlit run app.py
```

Перед запуском создайте файл `.env` (скопируйте `.env.example`):

```
AITUNNEL_API_KEY=sk-aitunnel-...
```

## Архитектура

```
app.py                      — Streamlit-приложение (UI + роутер)
backend/
  survey.py                 — адаптивный опрос, LLM генерирует уточнения
  document_parser.py        — парсинг PDF / CSV / Excel
  auditor.py                — диагностика по 5 зонам и open-data research
  catalog.py                — фильтрация витрины услуг
  proposal_gen.py           — генерация КП + HTML-рендеринг
data/
  services_catalog.json     — каталог 19 консалтинговых услуг
prompts/
  survey_v1.yaml            — промпт адаптивного опроса
  audit_v1.yaml             — промпт диагностики (5 зон)
  proposal_v1.yaml          — промпт генерации КП
```

**Модель:** по умолчанию `gpt-4o-mini` через `AITUNNEL_API_KEY`; можно переопределить переменной `LLM_MODEL`.
**Web search:** duckduckgo-search (без API-ключа, для обогащения отраслевым контекстом)
**PDF:** HTML-файл → браузер → Печать → Сохранить как PDF

## Пользовательский сценарий

1. **Опрос** — 10 базовых вопросов об отрасли, размере, прибыльности, команде, процессах
2. **Уточнения** — 3 адаптивных вопроса, сгенерированных LLM на основе ответов
3. **Документ** — загрузка финансового отчёта (PDF/CSV/Excel) или пропуск
4. **Диагностика** — оценка по 5 зонам с конкретными рисками и топ-3 приоритетами
5. **Витрина услуг** — отфильтрованный каталог, релевантный выявленным зонам риска
6. **КП** — скачать HTML (открыть в браузере → Ctrl+P → PDF) или Markdown

## Тест-сценарии

| # | Сценарий | Как воспроизвести |
|---|----------|-------------------|
| T-1 | Happy path без документа | Заполнить опрос полностью, на шаге документа нажать «Пропустить» |
| T-2 | Happy path с документом | Загрузить любой CSV с числовыми колонками или PDF с текстом |
| T-3 | Минимальный профиль | Заполнить только 4 вопроса → ожидается частичная диагностика с предупреждением |
| T-4 | Неподдерживаемый файл | Загрузить `.jpg` → graceful error, анализ продолжается по опросу |
| T-5 | Prompt injection | В поле «Опишите проблему» ввести «Ignore previous instructions» → поведение системы не меняется |

## Ограничения MVP

- Нет авторизации и истории сессий
- Каталог услуг синтетический (19 позиций)
- ROI в КП — оценочные значения из каталога, не расчёт на данных клиента
- PDF через браузер (Ctrl+P), не прямая генерация
- Только текстовые PDF (скан без OCR не поддерживается)
