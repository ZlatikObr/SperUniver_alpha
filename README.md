# Ревизор

**AI-аудитор списаний для среднего продуктового ритейла.**

SaaS-агент, который по выгрузке списаний из 1С (CSV/Excel) за 5 минут диагностирует структуру потерь сети и выдаёт приоритизированный план из 3 инициатив с расчётом ROI каждой.

> Проект для PDLC-интенсива «Low-code платформы», Бизнес-школа МФТИ × СберУниверситет, 4–6 мая 2026.
