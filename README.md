# Ревизор

**AI-инструмент первичного бизнес-скрининга для консалтинговых агентств.**

Клиент отвечает на вопросы о своём бизнесе, прикрепляет финансовые и маркетинговые отчёты (или обходится без них — тогда AI использует открытые данные), получает диагностику здоровья бизнеса и выбирает услуги из витрины консалтинга. На выходе — автоматически сгенерированное КП с презентацией.

> Проект для PDLC-интенсива «AI-driven PDLC», Бизнес-школа МФТИ × СберУниверситет, 4–6 мая 2026.

## Кому продаём

| Сегмент | Ценность |
|---|---|
| **Консалтинговые агентства** | Автоматизируют первичный скрининг клиентов, ускоряют подготовку КП с 3 дней до 30 минут |
| **Компании напрямую** | Получают независимый аудит бизнеса и понимают, какие услуги им реально нужны |

## Пользовательский сценарий

```
[1] Клиент открывает Ревизор (через сайт агентства или напрямую)
 ↓
[2] Проходит адаптивный опрос о бизнесе (отрасль, размер, выручка, ключевые боли)
 ↓
[3] Прикрепляет документы (фин. отчёт, маркетинг-план) — или пропускает
     → без документов: AI обогащает профиль открытыми данными
 ↓
[4] AI проводит аудит: находит зоны риска, формирует оценку здоровья бизнеса
 ↓
[5] Показывает витрину релевантных услуг с описанием, ROI и сроками
 ↓
[6] Клиент добавляет услуги в корзину
 ↓
[7] Система генерирует КП + презентацию (PDF / PPTX)
```
