# Тестовые данные

Эта папка — для синтетических датасетов, БД кейсов и адаптированных публичных данных.

См. подробный план в [`../docs/05-data-strategy.md`](../docs/05-data-strategy.md).

## Что здесь будет

```
data/
├── synthetic_writeoffs.csv   ← основной синтетический датасет (10к строк)
├── kaggle_adapted.csv        ← адаптированный публичный датасет
├── cases_db.json             ← БД из 10 кейсов (Auchan, Лента и т.д.)
└── edge_cases/               ← датасеты для тест-сценариев
    ├── small.csv             ← 1 месяц, 1 точка
    ├── dirty.csv             ← пропуски, разные форматы дат
    ├── empty.csv             ← нулевые списания
    └── wrong_columns.csv     ← негативный кейс
```
