# Стратегия по данным

## Три типа данных для MVP

### 1. Каталог услуг (`data/services_catalog.json`) — основа витрины

**Что:** 15–20 позиций консалтинговых услуг с описанием, зоной применения, ROI и ценой.

**Структура каждой позиции:**
```json
{
  "id": "fin-audit-01",
  "name": "Финансовый аудит",
  "zone": "финансы",
  "description": "Анализ P&L, cash flow и структуры затрат. Выявление точек потерь.",
  "industries": ["ритейл", "производство", "услуги"],
  "signals": ["отрицательный cash flow", "рост затрат без роста выручки"],
  "roi_estimate": "снижение затрат на 8–15% за 6 мес.",
  "duration_weeks": "4–6",
  "price_rub": "350000–600000"
}
```

**Зоны, по которым группируем услуги:**
- Финансы (аудит, оптимизация затрат, финансовое моделирование)
- Операции (процессный анализ, lean-трансформация)
- Маркетинг (анализ рынка, CJM, digital-стратегия)
- Команда (оргдизайн, HR-аудит)
- Стратегия (целеполагание, конкурентный анализ)

**Кто готовит:** Алсу (доменная экспертиза) — 2–3 часа.

---

### 2. Синтетические бизнес-профили (`data/test_cases/`) — тестирование

**Что:** 5 JSON-файлов с профилями вымышленных компаний для тест-сценариев.

**Профили:**
| Файл | Компания | Отрасль | Боль |
|---|---|---|---|
| `retail_ok.json` | Сеть магазинов «Уют» | Ритейл (18 точек) | Рост списаний, падение маржи |
| `services_growth.json` | Агентство «Вектор» | B2B-услуги | Хаотичный рост, нет процессов |
| `manufacturing_cash.json` | Завод «Технолит» | Производство | Кассовые разрывы, нет финмодели |
| `minimal_profile.json` | ИП Смирнов | Услуги | Минимум данных (edge case) |
| `injection_attempt.json` | — | — | Попытка prompt injection в полях |

**Как генерим:** Claude по промпту → проверяем вручную → сохраняем в репо.

---

### 3. Тестовые документы (`data/test_cases/docs/`) — проверка парсинга

**Что:** 3 файла-донора для проверки парсинга различных форматов.

| Файл | Формат | Содержимое |
|---|---|---|
| `sample_pl.pdf` | PDF | Синтетический P&L на 2 страницы |
| `sample_marketing.xlsx` | Excel | Синтетический маркетинговый отчёт (CAC, LTV, каналы) |
| `wrong_format.jpg` | JPG | Тест на graceful ошибку |

**Кто готовит:** Данила (генерация) + Данила/Алсу (проверка).

---

## Стратегия «без документа»: что делает AI

Если пользователь не прикрепил документ:
1. Claude получает структурированный профиль из опроса.
2. Использует `web_search` tool (встроен в Anthropic API) для поиска открытых данных по отрасли и сегменту.
3. Явно указывает в диагностике: «Анализ основан на ответах клиента и публичных отраслевых данных; без документов точность оценки снижается.»

**Что ищем в открытых данных:**
- Средние отраслевые показатели (маржа, CAC, churn) по отрасли клиента.
- Актуальные регуляторные риски в секторе.
- Публичные бенчмарки конкурентов (при наличии).

## Оценка трудозатрат

| Задача | Исполнитель | Часы |
|---|---|---|
| `services_catalog.json` (15–20 услуг) | Алсу | 3 |
| 5 синтетических профилей | Данила / Claude | 1 |
| 3 тестовых документа | Данила | 1 |
| **Итого** | | **~5 часов** |
