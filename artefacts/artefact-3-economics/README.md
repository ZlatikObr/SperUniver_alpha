# Артефакт 3 — Экономика и метрики

**Ответственная:** Злата Образумова  
**Срок:** День 3 интенсива.

## Чек-лист содержания

- [ ] **Cost-per-task** — стоимость одного полного аудита + генерации КП:
  - Токены input: ~25k (профиль + документ + промпты)
  - Токены output: ~8k (диагностика + КП)
  - Тариф Claude Sonnet 4.6 на дату питча
  - Инфра (Streamlit Cloud): ~$25/мес фикс

- [ ] **2 сценария:**
  - Base: 3 агентства × 20 аудитов/мес, цена подписки 30 000 ₽/мес
  - Optimistic: 10 агентств × 50 аудитов/мес + 20 прямых B2B-клиентов

- [ ] **Trade-offs:**
  - Sonnet 4.6 vs Haiku: глубина анализа vs стоимость (~8×)
  - С парсингом документа vs только опрос: точность диагностики vs скорость
  - PDF через weasyprint vs внешний сервис

- [ ] **ROI агентства-клиента:**
  - Высвобождение времени консультанта (×40% пресейла × ставка)
  - Конверсия опрос → КП → сделка
  - LTV / CAC агентства как нашего клиента

- [ ] **Ограничения и допущения:**
  - Тариф Anthropic фиксирован на дату расчёта
  - Не учитывает поддержку и онбординг агентства
  - Конверсия — гипотеза, не валидирована
