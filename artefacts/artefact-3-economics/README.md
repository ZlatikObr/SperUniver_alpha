# Артефакт 3 — Экономика и метрики

> Здесь будет финансовая модель: cost-per-task, base/optimistic, trade-offs, ROI, ограничения расчёта.

**Ответственная:** Злата Образумова

**Срок:** День 3 интенсива (параллельно с прототипом).

**Чек-лист содержания:**
- [ ] **Cost-per-task** — стоимость одного аудита:
  - Токены input: ~30к (CSV-сводка + промпты)
  - Токены output: ~10к (отчёт)
  - Тариф Sonnet 4.6 на дату питча
  - Латентность одного полного прогона (сек)
  - Инфра (Streamlit Cloud / Vercel) — фикс/мес
- [ ] **2 сценария:**
  - Base: 20 аудитов/месяц, цена 39 900 ₽
  - Optimistic: 80 аудитов/мес + 10 подписок
- [ ] **Trade-offs:**
  - Sonnet 4.6 vs Haiku: качество анализа vs цена в ~10×
  - С RAG vs без RAG: точность бенчмарков vs скорость
  - PDF локально vs внешний сервис: стоимость vs гибкость
- [ ] **ROI с привязкой к продуктовым метрикам:**
  - LTV / CAC
  - Конверсия freemium → paid
  - Retention подписчиков
  - Окупаемость одного клиента
- [ ] **Ограничения и допущения:**
  - Базируется на одном тарифе Anthropic (если изменится — пересчёт)
  - Не учитывает поддержку и продажи
  - Не учитывает churn

**Связь с другими артефактами:**
- Числа cost-per-task берутся из реальных логов прогонов в Артефакте 2
- ROI клиента = расчёт из Артефакта 1 (User Story «диагностика»)
