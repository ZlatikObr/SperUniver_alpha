# Артефакт 2 — Прототип AI-сервиса

> Здесь будет код прототипа: бэкенд-агент на Claude, парсинг CSV, RAG по кейсам, UI, генерация PDF, тесты.

**Ответственный:** Данила Шакин

**Срок:** Дни 2–3 интенсива.

**Будущая структура:**
```
artefact-2-prototype/
├── README.md           ← как запустить
├── pyproject.toml      ← зависимости
├── app.py              ← Streamlit UI
├── agent/
│   ├── orchestrator.py ← главный агент-оркестратор
│   ├── parser.py       ← парсинг CSV/Excel
│   ├── analyzer.py     ← структурный анализ pandas
│   ├── rag.py          ← поиск по БД кейсов
│   └── reporter.py     ← генерация PDF
├── prompts/            ← версионированные промпты YAML
├── configs/            ← бенчмарки, пороги
├── logs/               ← JSONL-логи запусков
└── tests/              ← 5+ тест-сценариев
```

**Чек-лист готовности (для Артефакта 2):**
- [ ] `make demo` запускает UI и работает E2E
- [ ] Главный сценарий проходит на синтетическом датасете
- [ ] AI-компонент: RAG + цепочка промптов + агент
- [ ] JSONL-лог каждого шага агента
- [ ] Промпты в YAML, не в коде
- [ ] 5+ тестов: базовый, грязные данные, маленький, аномалия, негативный
- [ ] README с инструкцией запуска
